04 / SELECTED WORK

A few areas I've worked on.

01
AUTHENTICATION MODERNIZATION

RSA MFA to Microsoft Authenticator and passwordless

I was part of the activity to move users from RSA MFA toward Microsoft Authenticator and passwordless authentication. We created pilot groups for users and devices and then enforced the changes based on the pilot results.

My work in this area includes Entra security groups, Conditional Access, Windows Hello for Business, FIDO2, passkeys, Temporary Access Pass and Authenticator. I also provide troubleshooting support when registration or authentication fails and help maintain the SOPs used by the team.

I'm also involved in defining the MFA exception process for automated service accounts. The current work is expanding to include Mac users.

02
BULK IAM OPERATIONS & AUTOMATION

Making repetitive Entra ID work faster

I regularly handle bulk operations such as user creation, invitations, re-invitations and group assignments. One bulk activity involved onboarding 575 users.

For recurring bulk operations, a process that could take around 3–4 hours manually with team effort can be completed in roughly 30 minutes using scripting. I use PowerShell, Microsoft Graph and Graph PowerShell for this work.

I also use scripts to generate reports such as client-secret expiry, certificate expiry, application owners, account inventory, application inventory and license inventory.

03
ZERO TRUST ASSESSMENT

From assessment findings to tenant security work

I ran a Zero Trust assessment script and generated the assessment report. The findings were shared with the client for review, and I am involved in implementing the resulting action items to improve the tenant's security.

04
HYBRID IDENTITY

Active Directory and Entra ID operations

My hybrid identity work includes user lifecycle management, Entra Connect-related operations and an OU restructuring activity. Users were previously in the same CN structure; the structure was reorganised into child OUs under the main OU and the change was completed.

I also supported an HR chatbot launch by providing Entra and UAM support, including Application Proxy installation and header-based SSO configuration.

05
APPLICATION IDENTITY

SSO, SAML, OIDC and application registrations

I work on SSO and SAML application registrations, enterprise applications, app roles, delegated and application permissions and SSO troubleshooting. I also coordinate with teams on EWS-to-Graph API application migration activities.

06
VPN AUTHENTICATION

Cisco VPN with Entra-based MFA

I supported the move from username/password VPN authentication to Entra-based authentication. The Cisco VPN was registered as an application in Entra, and access was controlled through security groups and a phishing-resistant MFA policy.

Users still need the required PFX VPN certificate installed on their local machine for the current-user VPN setup.

07
MICROSOFT 365 & EXCHANGE

Administration and access support

I also work with Microsoft 365 Admin Centre and Exchange activities, including distribution lists, shared mailboxes, mail contacts, mailbox permissions and license assignments. My UAM scope also includes shared-folder access management.

05 / INCIDENT HANDLING

When an identity issue comes in, I work backwards from the error.

01 Start with the sign-in logs I check what actually failed — MFA, credentials, SSO or another authentication condition.
02 Check the Conditional Access result I identify which policy was evaluated and what caused it to fail.
03 Check the application For SSO issues, I check the application and how SSO is configured.
04 Resolve or coordinate I follow the approved access process, involve the relevant team when needed, validate the result and communicate the outcome.
